
## 一、内容逻辑架构：金字塔原理

采用**金字塔结构**来组织内容 ：

### 核心结构：SCQA 模型
**S（情境/背景）** 建立共鸣，让读者代入 | "你有没有过这样的时刻，看着身边的朋友事业有成..." |
**C（冲突）** 指出痛点或问题 | "而自己却好像一直在原地踏步..." |
**Q（疑问）** 引发好奇心 | "如何才能改变这种状态？" |
**A（答案）** 提供解决方案 | "30岁前一定要逼自己养成这5个习惯..." |

### 纵向关系：疑问/回答式对话
文章通过**不断制造疑问→回答**的方式推进，像悬疑小说一样吊着读者胃口 ：
- "为什么会这样？" → 解释原因  
- "怎么才能这样？" → 提供方法  
- "为什么你会这样认为？" → 给出证据

## 二、视觉排版架构：模块化设计

热门公众号采用**模块化排版**，将内容划分为清晰的功能区块，每个区块承担不同的信息传达任务 ：

### 标准模块构成

┌─────────────────────────────────────┐
│  1. 引导关注区（顶部）                │  ← "点击蓝字，关注我们" + 头图
├─────────────────────────────────────┤
│  2. 开篇导语区                        │  ← SCQA中的S和C，建立共鸣
├─────────────────────────────────────┤
│  3. 核心内容区（可重复）              │  ← 小标题 + 正文 + 配图
│     ├─ 小标题（H2/H3）               │
│     ├─ 引导句/金句                   │
│     ├─ 正文段落（3-5行/段）          │
│     ├─ 强调元素（加粗/色块/引用）     │
│     └─ 配图/图表                     │
├─────────────────────────────────────┤
│  4. 互动/转化区                       │  ← 引导评论、点赞、转发
├─────────────────────────────────────┤
│  5. 结尾关注区（底部）                │  ← 二维码 + 品牌信息
└─────────────────────────────────────┘


## 三、信息层级架构：信噪比控制

优秀公众号通过**信息层级设计**降低阅读负担，提升信息获取效率 ：

### 层级划分（从上到下重要性递减）
1. **一级信息**：标题、头图、核心数据（红色高亮）
2. **二级信息**：小标题、关键结论（加粗/品牌色）
3. **三级信息**：正文内容、案例描述
4. **四级信息**：注释、引用、辅助说明（灰色弱化）

### 视觉降噪原则
- **去除多余元素**：分割线、装饰icon最小化 
- **加大字号对比**：标题明显大于正文，副标题居中
- **控制颜色数量**：主色（品牌色）+ 辅助色（黑灰）+ 强调色（红/橙）
- **留白艺术**：段前段后留白、图片周围留白

## 四、内容组织逻辑：经典结构

根据爆款文章分析，内容组织逻辑 ：

### 1. 总分总结构（最常用）
- **总起**：开头提出核心观点或问题
- **分述**：中间分点阐述（习惯一、习惯二... / 技巧A、技巧B...）
- **总结**：结尾升华主题，呼吁行动

**案例**："30岁前一定要逼自己养成这5个习惯" → 分别讲5个习惯 → 结尾鼓励行动

## 五、图文混排架构：移动端适配

针对手机阅读场景，热门公众号遵循特定的图文混排逻辑 ：

### 基本原则
- **竖向流式**：避免左右分栏，采用"图片→文字→图片→文字"的垂直流 
- **全宽图片**：图片尽量充满屏幕宽度（677px），提升视觉冲击力
- **图文比例**：图版率（图片占比）控制在30%-50%，避免纯文字疲劳

### 多图排版方案 
| 图片数量 | 推荐布局 | 适用场景 |
|----------|----------|----------|
| 1张 | 全宽大图，文字叠加或上下环绕 | 封面图、重点展示 |
| 2张 | 左右对比、上下排列 | 对比展示、前后对比 |
| 3张 | 横向并列、三图滑动 | 多角度展示、步骤分解 |
| 4张+ | 网格组合、滑动轮播 | 作品集、产品展示 |

## 六、交互架构：SVG 与动态元素

高阶公众号采用**SVG 交互组件**提升阅读体验 ：

### 常见交互模块
- **点击展开**：点击后展开更多内容，节省首屏空间
- **滑动切换**：左右滑动查看多张图片，增加停留时长
- **轮播动效**：自动轮播或手动切换，提升灵动感
- **推窗动效**：模拟开窗效果，增强沉浸感

## 七、建议

基于以上架构，应该支持：

### 1. 模板系统（按内容类型）
- **干货教程模板**：信息图式，步骤分解，图标列表
- **情感故事模板**：杂志风，大图留白，金句突出
- **观点论述模板**：对话体，引用块，层级标题
- **品牌宣传模板**：长图文，时间轴，数据可视化

### 2. 模块化组件库
- **头部组件**：关注引导、头图、摘要
- **内容组件**：小标题、正文、引用、列表、代码块
- **图文组件**：单图、双图对比、多图滑动、图文叠加
- **交互组件**：滑动轮播、进度条
- **尾部组件**：二维码、引导关注、版权信息

### 3. 智能排版逻辑
- 自动识别内容类型（教程/故事/观点）并匹配模板
- 自动划分内容区块（标题、段落、列表）并应用样式
- 自动优化信息层级（重要内容自动高亮）
- 自动适配移动端（图片宽度、字体大小、行间距）
